2. RINCIAN KOMPONEN SISTEM
-----------------------------------------------------------------------------------------------------------------------

A. CLIENT LAYER (FRONTEND & UI)
   • Framework: SvelteKit 3 dengan Svelte 5 Runes ($state, $derived, $effect)
   • Styling: Tailwind CSS v4 (Desain Solid Colors, High Contrast, No Gradients)
   • Navigation: Smart Auto-Hide Header saat scroll turun, Persistent Bottom Navigation di Mobile
   • Responsive Breakpoints: Dukungan penuh Mobile Portrait, Mobile Landscape, Tablet, dan Desktop
   • Audio Synthesizer: soundStore.ts memanfaatkan native Web Audio API (Osilator matematis tanpa file mp3 besar)

B. CODING GAME ENGINE & COMPILER (DETERMINISTIK NON-LLM)
   • Block Workspace: Editor penyusunan balok visual drag-and-drop ala Scratch 3
   • Atomic Blocks: MAJU, BELOK KIRI, BELOK KANAN, ULANGI (N KALI), SELAMANYA
   • Compiler AST: compiler.ts menerjemahkan susunan balok ke Atomic Commands dan kode Python real-time
   • Game Loop Engine: engine.ts mensimulasikan pergerakan robot PyBot, tabrakan rintangan, dan target koin/bintang
   • Solvability Solver: validator.ts menggunakan algoritma Breadth-First Search (BFS) untuk membuktikan secara
     matematis bahwa seluruh 90 misi labirin dapat diselesaikan tanpa galat rintangan (minMoves <= maxMoves)

C. MODUL PEMBELAJARAN & EVALUASI KUIS
   • Kurikulum: 30 Level Modul Belajar Logika Python
   • Bank Soal: 150 Soal Konseptual interaktif (5 soal per level)
   • Scoring Engine: quizEvaluator.ts dengan proteksi double-counting dan kalkulasi akurat (Correct/Wrong/Score/Streak)

D. STATE MANAGEMENT & AUTENTIKASI
   • Auth System: Integrasi resmi Google Identity Services (OAuth 2.0)
   • Isolasi Akun: Penyimpanan progres diisolasi per ID pengguna sehingga progres akun baru tidak tercampur akun lama
   • Guest Mode: Dukungan mode tamu lokal tanpa keharusan login awal

E. OFFLINE-FIRST PWA & DEPLOYMENT
   • Service Worker: Precaching shell aplikasi dan runtime caching aset statis
   • Web App Manifest: PWA Standalone dengan maskable icons 192x192 & 512x512
   • Hosting: Vercel Edge Serverless Deployment dengan waktu build produksi ~3-4 detik
